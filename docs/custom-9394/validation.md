## 用户手动验收（2026-10-19 更新）

1. 下载本次已通过校验的 artifact ZIP，解压后将 armv7-signed.apk 安装到雷电模拟器。记录实际 Android 版本、APK SHA-256 和安装提示；未安装成功时不标记兼容通过。
2. 打开 APP，观察 RustDesk Input 未开启时的引导；在系统设置中开启并返回。按屏幕捕获、电池优化及悬浮窗的实际系统提示授权，检查返回 APP 后是否自动继续启动服务。拒绝或取消时不应循环弹窗或伪造已授权状态。
3. 在网络设置核对 ID/中继/API/Key 四项；检查一次性密码首次和刷新均为六位数字。用自己的控制端连接模拟器生成的 ID，分别验证临时密码和约定的固定密码，避免在公开反馈中附带口令。
4. 分别验证远程画面、鼠标/键盘输入、文件上传下载和双向剪贴板；文件传输按上游的应用专属工作区及系统文件选择器能力测试。
5. 检查开机选项、授权后模拟器重启、后台返回和断线重连；主动停止服务后不应在当前会话反复自动拉起。修改密码/服务器或开关后重启，应保留用户设置。
6. 反馈未通过项时提供 APK 版本/摘要、系统版本、复现步骤及错误提示或截图。后续仍先将问题补入需求文档，再修改代码和重新构建。商米 T2 真机资源及稳定性验收保持待执行。
